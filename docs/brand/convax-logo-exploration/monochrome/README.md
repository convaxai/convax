# Convax monochrome logo study

Eight black-and-white directions generated as a fresh exploration. Every candidate
uses a 100 × 100 coordinate system, a white full-bleed rounded container, transparent
outer corners, and a near-black `currentColor` mark. Production currently uses the
colored **Stacked Context** direction; this monochrome set remains an unwired study.

Open `index.html` to compare the marks at different sizes. `size-check.svg` shows
the actual 16 px, 32 px, and 64 px raster footprint side by side.
