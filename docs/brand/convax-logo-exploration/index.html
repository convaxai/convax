Convax · App Icon Study

Eight directions.
No monograms.

统一使用白色圆角 app 容器与 Convax 紫色。八个方案分别探索协作、涌现、无限画布、负空间、引导路径、共创、上下文层叠和模块化。

01 / PURE GEOMETRIC

Synthesis Lens

两块独立空间在重叠处产生新语境，表达用户与 AI 的协同，而非字母。

02 / DOT MATRIX

Emerging Field

信息从一个主焦点逐步涌现，适合表达 Agent 将分散素材组织为结果。

03 / LINE SYSTEM

Infinite Flow

多条连续轨迹形成开放表面，表达无边画布和持续推进的工作流。

04 / NEGATIVE SPACE

Selective Void

从完整形体中减去少量信息，象征 AI 识别重点、留出思考空间。

05 / GEOMETRY + LINE

Guided Surface

稳定的画布边界与一条智能路径叠加，强调 Agent 在空间中执行操作。

06 / ORGANIC NODES

Co-creation

两个尺度不同的思考体融合成一个结果，保留一点有机感和非对称张力。

07 / LAYERED GEOMETRY

Stacked Context

两层旋转的圆角画布代表 Project 与 Canvas、素材与上下文的组合。

08 / MODULAR SYSTEM

Modular Field

四块不同尺度的内容单元形成开放工作区，直指文件、节点和画布布局。
