# Convax logo exploration

Eight distinct app-icon directions generated with the `logo-generator` skill.
**Stacked Context** is the selected production Electron icon; the remaining
directions stay here as design-history references.

1. **Synthesis Lens** — pure geometry; human and AI context overlap.
2. **Emerging Field** — asymmetric dots; scattered inputs become an outcome.
3. **Infinite Flow** — dense line system; continuous infinite-canvas workflow.
4. **Selective Void** — punched geometry; intelligence through subtraction.
5. **Guided Surface** — frame plus path; Agent action inside a Canvas.
6. **Co-creation** — organic merged form; user and AI produce one result.
7. **Stacked Context** — layered planes; Project, Canvas, and context.
8. **Modular Field** — bento geometry; files and nodes arranged spatially.

Open `index.html` for the interactive comparison, including 64px, 32px, and 16px previews.
